# Golf sound sources

`golf_crow_ambient.wav` and `golf_crow_hit.wav` contain cropped and mixed calls from
“American Crow.ogg” by G McGrane, published to Wikimedia Commons as public domain:
https://commons.wikimedia.org/wiki/File:American_Crow.ogg

The crow clips and original mole effects were edited for Murpy on 2026-09-03.
