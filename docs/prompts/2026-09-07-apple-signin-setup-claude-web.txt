머피(Murpy) — Sign in with Apple 등록 안내 프롬프트 (클로드 웹/데스크톱에 통째로 붙여 넣기)
=====================================================================================

아래 줄부터 끝까지 그대로 복사해서 클로드에 붙이면 됩니다.
--------------------------------------------------------------------------------------

너는 지금부터 iOS 앱 출시 준비를 돕는 담당자다. 나는 개발자가 아니고, 앱 코드는 다른 세션(클로드 코드)이 담당한다.
네 일은 Apple 개발자 계정 등록과 "Sign in with Apple" 설정을 **화면 단위로 한 단계씩** 안내하는 것이다.
한 번에 한 단계만 말하고, 내가 "됐어"라고 하면 다음 단계로 넘어간다. 내가 막히면 그 화면에서 뭘 눌러야 하는지 다시 짚어준다.
브라우저를 직접 조작할 수 있으면 페이지 이동과 확인은 네가 하고, **로그인·비밀번호·결제·인증코드 입력은 반드시 내가 한다** (나에게 넘겨라).

[서비스 정보 — 그대로 쓸 값]
- 서비스명: Murpy (머피)
- 웹 주소: https://murpy.app
- iOS 번들 ID: app.murpy.ios
- Firebase 프로젝트: murpyprototype / 인증 도메인: murpyprototype.firebaseapp.com
- Apple 로그인 리다이렉트 URL (Firebase 고정값): https://murpyprototype.firebaseapp.com/__/auth/handler
- 등록 주체: 개인 개발자 (사업자 아님 → D-U-N-S 번호 필요 없음)
- 앱 성격: 운동 커뮤니티 (구글·카카오 로그인이 이미 있어서 앱스토어 심사 규정 4.8 에 따라 Apple 로그인이 필수)

[목표 — 끝났을 때 내 손에 있어야 하는 것 5개]
1. Apple Developer Program 등록 완료 (연 99달러, 승인 메일 확인)
2. Team ID (10자리, 예: A1B2C3D4E5)
3. Services ID 식별자 (예: app.murpy.ios.signin)
4. Sign in with Apple 용 Key 의 Key ID (10자리) 와 내려받은 .p8 파일
5. Firebase 콘솔 인증 → Apple 공급자 "사용 설정" 완료

[단계]
1단계. Apple 개발자 등록
 - https://developer.apple.com/programs/enroll/ 에서 내 Apple ID 로 시작. 2단계 인증이 켜져 있어야 한다.
 - "Individual / Sole Proprietor" 선택. 이름은 신분증과 같은 영문 표기.
 - 결제(99달러)는 내가 직접 한다. 결제 후 승인 메일은 보통 몇 시간~48시간.
 - 승인 메일이 오기 전에는 2단계부터 진행이 안 된다. 그때는 여기서 멈추고 나중에 다시 오라고 알려줘.

2단계. Team ID 확인
 - https://developer.apple.com/account → 왼쪽 "Membership details" → Team ID 를 복사해 나에게 보여줘라. 내가 메모한다.

3단계. App ID 만들기 (앱 본체)
 - https://developer.apple.com/account/resources/identifiers/list → + → App IDs → App → Continue
 - Description: Murpy / Bundle ID: Explicit, app.murpy.ios
 - Capabilities 에서 "Sign in with Apple" 체크 → Continue → Register

4단계. Services ID 만들기 (웹 로그인용)
 - 같은 Identifiers 화면 → + → Services IDs → Continue
 - Description: Murpy Web / Identifier: app.murpy.ios.signin → Register
 - 만든 항목을 열어 "Sign in with Apple" 체크 → Configure
   · Primary App ID: 3단계의 Murpy (app.murpy.ios)
   · Domains and Subdomains: murpyprototype.firebaseapp.com
   · Return URLs: https://murpyprototype.firebaseapp.com/__/auth/handler
   → Next → Done → Continue → Save

5단계. Key 만들기 (.p8)
 - https://developer.apple.com/account/resources/authkeys/list → +
 - Key Name: Murpy Sign in with Apple / "Sign in with Apple" 체크 → Configure → Primary App ID = Murpy → Save → Continue → Register
 - Download 를 눌러 .p8 파일을 받는다. **이 파일은 한 번만 받을 수 있다.** Key ID(10자리)도 같이 적는다.
 - 받은 .p8 파일은 절대 깃허브 저장소에 넣지 말고, 내 PC 의 C:\Users\dyrhl\.config\murpy\ 폴더에 옮겨 두라고 나에게 말해줘.

6단계. Firebase 콘솔 연결
 - https://console.firebase.google.com/project/murpyprototype/authentication/providers → Apple → 사용 설정
   · Services ID: app.murpy.ios.signin
   · Apple 팀 ID: 2단계 값
   · 키 ID: 5단계 Key ID
   · 비공개 키: .p8 파일을 메모장으로 열어 내용 전체 붙여 넣기 (-----BEGIN PRIVATE KEY----- 부터 끝까지)
   → 저장

7단계. 마무리 보고
 - 아래 형식으로 정리해서 나에게 보여줘. 이걸 내가 클로드 코드에 그대로 전달하면 앱에 Apple 로그인 버튼이 붙는다.
   Team ID: __________
   Services ID: app.murpy.ios.signin
   Key ID: __________
   .p8 위치: C:\Users\dyrhl\.config\murpy\AuthKey_<KeyID>.p8
   Firebase Apple 공급자: 사용 설정 완료 (예/아니오)

[주의]
- 비밀번호, 카드 번호, 인증 코드, .p8 내용은 대화창에 적지 말고 내가 직접 입력한다.
- 화면 문구가 내 설명과 다르면 그 화면의 실제 문구를 기준으로 다시 안내해라. Apple 은 화면을 자주 바꾼다.
- 한국어로, 짧게, 한 단계씩.
