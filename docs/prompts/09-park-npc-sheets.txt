== keeper 관리인 박씨 ==

== trainer 강 코치 ==
'강 코치' — 20대 후반 한국 남성 피트니스 트레이너. 밝고 자신 있는 얼굴(씩 웃음).

== grandma 순이 할매 ==

- 머리: 은회색 머리를 뒤로 모아 쪽진 머리(둥근 한 덩어리, 후면에 작은 쪽 표현).
- 옷: 겨자색 카디건(단추 납작한 점 3개), 갈색 긴 치마(발목까지), 검은 단화.

== kid 민준이 ==
