아래는 저장소를 직접 열어 확인한 사실입니다. 추측이 아니라 실측입니다.
대표는 비개발자입니다. 전문용어는 쓰되 바로 쉬운 말로 풀어 주세요. 한국어 존댓말.

-------------------------------------------------------------------------
0. 지금 앱이 어떤 모양인가 (가장 먼저 이해할 것)
-------------------------------------------------------------------------
머피는 **웹앱(PWA)** 입니다. 앱 전체가 index.html 한 파일이고 https://murpy.app 에
올라가 있습니다. 스토어에 올리는 앱은 그 웹사이트를 **껍데기 앱이 감싸서 보여주는**
방식입니다(웹뷰 래퍼). 두 껍데기 모두 PWABuilder 로 만들어져 있습니다.

  - iOS  : ios/src/  (Xcode 프로젝트, Swift)
  - 안드로이드 : 저장소에 소스는 없고, TWA 방식으로 등록만 준비돼 있음

즉 **앱 안의 기능을 고치려면 index.html 을 고치고 웹에 배포**하면 스토어 재심사 없이
바로 반영됩니다. 껍데기는 거의 안 건드립니다.

2. ★★막힐 것들 (등록 전에 반드시 처리) — 심각한 순서
-------------------------------------------------------------------------

【1】 애플 로그인(Sign in with Apple)이 **없습니다** → App Store 반려 확정급
  현재 로그인 = 구글 + 카카오 두 가지뿐입니다(index.html 확인).
  Apple 심사지침 4.8 : 제3자 소셜 로그인을 제공하면 **동등한 개인정보 보호 로그인**을
  같이 제공해야 합니다. 사실상 'Sign in with Apple' 을 넣으라는 뜻입니다.
  → 이걸 안 넣으면 앱스토어는 거의 확실히 반려됩니다.
  할 일 : Firebase Auth 에 Apple 공급자 추가 + Apple Developer 에서 Service ID·Key 발급
         + index.html 로그인 화면에 애플 버튼 추가(기존 구글/카카오 버튼과 같은 문법으로).
  ※플레이스토어는 이 요건이 없습니다. 안드로이드만 먼저 내는 것도 방법입니다.

【2】 iOS 껍데기에서 **소셜 로그인이 안 열릴 가능성이 매우 높음**
  ios/src/Murpy/Settings.swift 의 `authOrigins` 가 **비어 있습니다**(빈 배열).
  이 값은 "로그인 창은 별도 창으로 띄운다"는 목록인데, 아무것도 안 적혀 있습니다.
  게다가 구글은 **앱 안에 심어진 웹뷰에서의 OAuth 로그인을 정책적으로 차단**합니다
  (disallowed_useragent 오류). 카카오도 같은 제약이 있습니다.
  → 실기기에서 **로그인 자체가 안 될 수 있습니다. 제출 전에 반드시 실제 아이폰에서
     구글 로그인·카카오 로그인을 눌러 끝까지 되는지 확인하세요.**
  안 되면 두 가지 중 하나:
    (a) authOrigins 에 accounts.google.com, kauth.kakao.com 을 넣고 Info.plist 에도 추가
    (b) (권장) 로그인만 ASWebAuthenticationSession(사파리 창)으로 띄우도록 Swift 수정
  ★이건 스토어 심사 이전에 '앱이 아예 못 쓰는' 문제라 1순위로 확인하세요.

【3】 권한 설명 문구가 영어 기본값입니다 → Apple 5.1.1 반려 사유
  현재 Info.plist :
    NSCameraUsageDescription     "Capture Video by user request"
    NSMicrophoneUsageDescription "Capture Audio by user request"
    NSLocationWhenInUseUsageDescription "Track current location by user request"
  이건 PWABuilder 기본 문구입니다. Apple 은 **왜 필요한지 구체적으로** 적으라고 요구합니다.
  한국어로 바꾸세요. 예:
    카메라 : "운동 인증 사진을 찍고 프로필 사진을 등록하기 위해 카메라를 사용합니다."
    위치   : "가까운 헬스장을 찾고 센터 체크인을 확인하기 위해 현재 위치를 사용합니다."
  ★★마이크는 **지우세요.** 앱을 검사한 결과 마이크를 쓰는 곳이 한 군데도 없습니다
    (카메라 호출 두 곳 모두 audio:false — 영상만 씁니다). 안 쓰는 권한을 선언하면
    그 자체가 반려 사유이고, 심사자가 "왜 마이크가 필요하냐"고 묻습니다.
    → Info.plist 에서 NSMicrophoneUsageDescription 항목을 삭제.

【4】 Apple Developer 팀이 설정돼 있지 않습니다
  DEVELOPMENT_TEAM 이 빈 값입니다. Apple Developer Program 가입(연 $99, 개인 자격) 후
  Xcode 에 팀을 연결해야 빌드·업로드가 됩니다. 맥과 Xcode가 필요합니다.
  ※맥이 없으면 iOS 는 당장 불가능합니다. 이 경우 **플레이스토어부터** 진행하세요.

【5】 "웹사이트를 그냥 감싼 앱" 반려 위험 (Apple 4.2 최소 기능)
  Apple 은 웹뷰만 띄우는 앱을 반려하는 경우가 있습니다. 방어 재료는 이미 있습니다:
   · 푸시 알림, 카메라, 위치(체크인), 홈화면 아이콘, 오프라인 캐시
  심사 메모에 "PWA를 감싼 것이 아니라 네이티브 푸시/카메라/위치를 쓰는 커뮤니티 앱"이라고
  적고, 심사자용 테스트 계정을 반드시 제공하세요.

【6】 사진 업로드가 imgBB 무료 키 하나에 걸려 있습니다
  전 유저가 키 하나를 공유하고, 그 키가 **공개 저장소에 노출**돼 있습니다.
  8-19 에 imgBB 점검으로 전 유저 인증 업로드가 멈춘 적이 있습니다.
  → 스토어 반려 사유는 아니지만, 출시 후 터지면 앱이 통째로 멈춥니다.
    Cloudflare Worker 나 Cloud Functions 프록시로 옮기는 것을 강력히 권합니다.

【7】 머피(크레딧) 지급을 클라이언트가 판정합니다
  브라우저에서 조작될 수 있습니다. 규칙으로 1회 1000 증가 상한만 걸어 둔 상태입니다.
  유료 결제를 붙이기 전에 반드시 서버(Cloud Functions)로 옮겨야 합니다.
  ※지금은 결제가 없으므로 출시 자체를 막지는 않습니다.

     ※2023년 이후 개인 개발자는 **20명 비공개 테스트 14일**을 거쳐야 프로덕션 출시가
       열립니다. 이 규정 적용 대상인지 콘솔에서 확인하세요. 대상이면 오늘 출시는 불가능하고

  2) 앱 패키지(AAB) 만들기 — https://www.pwabuilder.com 에 murpy.app 입력 → Android 패키지 다운로드
     ★패키지명은 반드시 **app.murpy.twa** 로 (이미 게시된 assetlinks.json 과 맞아야 함)
     ★내려받은 zip 안의 **서명 키(signing key)와 비밀번호를 절대 잃어버리지 마세요.**

     ★Play App Signing 을 쓰면 구글이 최종 서명키를 관리하는데, 그 경우 콘솔이 알려주는
       **새 SHA256 지문으로 assetlinks.json 을 갱신**해야 주소창이 사라집니다.
       (지금 파일의 지문과 다르면 앱 위에 주소창이 뜹니다 — 등록 후 실기기로 꼭 확인)

  · 사용자가 쓴 글·댓글·채팅

  Google Data safety / Apple 개인정보 라벨 작성 시:
   - 수집함 : 이메일, 이름(닉네임), 사진, 위치(대략/정확), 사용자 콘텐츠, 기기 식별자

   - 데이터 삭제 요청 경로 : 앱 내 '계정 삭제' 버튼 + privacy 페이지 문의처
   - 전송 중 암호화 : 예 (HTTPS)

★위 내용이 https://murpy.app/privacy 문서와 **어긋나면 안 됩니다.** 제출 전에 privacy.html
  을 열어 위 항목이 전부 적혀 있는지 대조하세요. 특히 위치·imgBB 부분.

5. 사업자 관련 (이미 정해진 전략 — 어기면 지원금 자격 상실)
-------------------------------------------------------------------------
 · 출시는 **개인 개발자 계정**으로 합니다. 사업자등록 필요 없습니다.
 · ★예비창업패키지 신청 전까지 **세무서 사업자등록을 절대 하지 마세요.**
   예창패는 '사업자등록 이력이 없는 예비창업자' 대상이라 미리 내면 자격이 사라집니다.
 · ★국세 체납이 결격 사유가 될 수 있습니다. 부가세 2건 약 591,430원 체납분을
   신청 전에 완납하고 납세증명서가 깨끗하게 발급되는지 확인하세요.
 · 투자를 받으려면 개인사업자가 아니라 **법인**이 필요합니다(VC는 지분 투자).
 · 순서 : 개인 계정 출시 → 사용자 확보 → 체납 정리 → 예창패 신청·선정 → 법인 설립 → 앱 이전
   (Google Play 는 개인→사업자 앱 이전 가능. Apple 은 새 법인 계정을 만들고 앱만 Transfer)
