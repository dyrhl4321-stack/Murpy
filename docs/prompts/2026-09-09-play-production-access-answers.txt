1단계: 비공개 테스트 정보
────────────────────────────────────────────────────────────────
▶ 테스터 모집이 얼마나 쉬웠나요?  → 「쉬웠음」 선택

▶ 테스터가 제공되는 모든 앱 기능을 사용했는지
테스터는 앱의 주요 기능을 모두 사용했습니다. 운동 인증(사진 촬영·AI 얼굴 확인·피드 게시), 같은 헬스장 회원 매칭(좋아요·수락·채팅),
스쿼드(모임 개설·참가·출석 코드·범프 출석), 대나무숲(익명 글·댓글), 머피월드(캐릭터 꾸미기·내 방 인테리어·펫·공원 오픈월드·미니게임·
헬스장 체크인·머피캠 사진)을 안내 문서에 따라 순서대로 써 보게 했고, 특히 로그인(구글·카카오), 사진 업로드, 푸시 알림, 키보드가 뜨는
입력 화면을 여러 기종에서 반복 확인하게 했습니다.

▶ 테스터의 사용 방식이 프로덕션 사용자의 예상 행동과 일치하는지 (차이점 포함)
대체로 일치합니다. 실제 사용자는 헬스장에서 운동 직후 인증 사진을 올리고 같은 헬스장 사람에게 매칭을 보내는 흐름이 중심인데,
테스터도 같은 순서로 썼습니다. 차이점은 두 가지였습니다. (1) 테스터는 실제 헬스장에 있지 않아 GPS 반경 체크인과 두 기기를 맞대는
범프 출석을 실제 현장 조건으로는 검증하지 못했고, 이 부분은 운영자와 운동 커뮤니티 회원(247명 규모)이 실제 헬스장에서 별도로
검증했습니다. (2) 테스터는 짧은 기간에 여러 기능을 훑는 편이라 하루 1회 인증·스트릭 같은 장기 반복 기능은 커뮤니티 회원의
2주 이상 사용 기록으로 보완했습니다.

▶ 테스터로부터 받은 의견 요약 + 수집 방법
수집 방법: 앱 안의 「피드백 보내기」 기능(서버에 저장), 카카오톡 단체방, Google Play 비공개 테스트 의견, 운영자와의 1:1 대화.
주요 의견과 조치:
 - 설치한 앱 위에 브라우저 주소창이 보인다 → 앱 서명 키 지문을 자산 링크에 추가해 해결.
 - 게임(홀인 머피) 이미지가 일부 폰에서 안 뜬다 → 이미지 캐시 정책을 바꿔(깨진 캐시 무효화·정상 응답만 저장) 해결.
 - 글쓰기 화면에서 키보드가 올라오면 버튼이 가려진다 / 사진 업로드 뒤 스크롤이 튄다 → 입력 화면 레이아웃 수정.
 - 아이폰에서 필드 탭 이동이 가끔 씹힌다 → 터치 처리 수정.
 - 캐릭터 얼굴 커스터마이징 결과가 낯설다(옆모습·정면) → 생성 파이프라인 후처리 추가, 폐기·이의신청·재생성 흐름 추가.
 - 이름표·이모트·보상 화면이 밋밋하다 → 도트 이름표 6종, 이모트 27종, 보상 안내 애니메이션으로 교체.
 - 공원(오픈월드)에 사람이 있는지 알 수 없다 → 홈 화면에 실시간 접속 인원 카드와 바로 입장 버튼 추가.

2단계: 앱/게임 정보
────────────────────────────────────────────────────────────────
▶ 앱의 가치 제안
머피는 「같이 운동할 사람을 찾는 앱」입니다. 사용자는 헬스장에서 운동 인증 사진을 올려 실제로 운동하는 사람임을 증명하고,
같은 헬스장·같은 동네에서 인증 기록이 있는 사람과 연결됩니다. 오프라인 모임(스쿼드)을 열고 출석 코드나 두 기기를 맞대는 범프로
출석을 확인할 수 있어, 운동 커뮤니티 운영자가 카카오톡 단체방 대신 쓸 수 있는 운영 도구가 됩니다. 픽셀 아바타와 머피월드(내 방·공원·
미니게임)는 인증을 꾸준히 하게 만드는 보상 장치입니다. 앱 안의 모든 아이템은 코스메틱이며 매칭 노출에 영향을 주지 않습니다.

▶ 출시 첫해 예상 설치 수  → 「1,000 ~ 10,000」 선택
 (근거: 운영 중인 운동 커뮤니티 247명 + 서울 헬스장 단위 확장 계획. 더 큰 구간을 고르면 설득 근거를 요구받을 수 있음)

3단계: 프로덕션 준비 상태 정보
────────────────────────────────────────────────────────────────
▶ 비공개 테스트에서 알게 된 내용을 바탕으로 앱을 어떻게 변경했는지
테스트 기간(8월 말~9월 초) 동안 500건 이상의 수정을 배포했습니다. 대표적으로:
 - 안정성: 설치 앱 주소창 제거(자산 링크 서명 지문), 서비스워커 이미지 캐시 정책 교체(깨진 캐시로 게임 이미지가 안 뜨던 문제),
   iOS 오디오 컨텍스트 중단 처리, 스크롤 잠금 전수 점검, 아이폰 터치 좌표 보존.
 - 입력 화면: 키보드가 뜰 때 버튼이 가려지던 레이아웃, 사진 업로드 후 스크롤 튐, 글쓰기 화면 배경 투명 문제.
 - 보안/경제: 앱 화폐 증가를 클라이언트에서 막고 서버 검증으로 이관, 결제 관련 규칙 강화, 알림 위조 차단.
 - 기능 완성도: 얼굴 커스터마이징 후처리·폐기·이의신청 흐름, 공원 오픈월드 3개 맵과 NPC 퀘스트, 보상 안내 화면,
   이름표·이모트 시스템, 홈 화면 실시간 접속 카드와 딥링크, 친구가 공원에 들어오면 알리는 푸시(빈도 제한 포함).

▶ 프로덕션 준비를 마쳤다고 판단한 근거
 - 테스터 12명이 14일 이상 참여했고, 그 사이 위 문제들을 모두 수정해 마지막 빌드에서는 튕김·기능 불능 보고가 없습니다.
 - 실제 운동 커뮤니티 회원(247명 규모)이 웹 버전을 수 주간 사용하며 인증·매칭·스쿼드 출석을 실제 헬스장에서 검증했습니다.
 - 로그인(구글·카카오·이메일), 사진 업로드, 푸시 알림, 위치 체크인이 여러 안드로이드 기종에서 동작함을 확인했습니다.
 - 데이터 보안 양식, 콘텐츠 등급, 개인정보처리방침·이용약관, 계정 삭제 기능, 심사자용 테스트 계정을 모두 준비했습니다.
 - 부적절한 콘텐츠 신고·차단 기능과 연락처 교환 차단 필터를 갖췄고, 유료 결제는 아직 없어 결제 정책 위반 소지가 없습니다.
