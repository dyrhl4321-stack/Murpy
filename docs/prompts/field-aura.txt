머피 필드 아우라 (히든 아티팩트) — 이미지 생성 프롬프트
v2 (2026-08-18) — 1차 시안이 너무 과해서 다시 씀

■ 이게 뭔지
헬스장 필드 바닥 합판을 열면 나오는 보상. 캐릭터 "뒤편"에 깔리는 아우라 이펙트다.
시즌마다 다른 아우라로 교체한다. 캐릭터 본체는 절대 안 건드린다.

■ ★v1 이 왜 과했나 (다시 뽑기 전에 읽을 것)
바람의나라 스킬은 **순간** 이펙트다. 0.5초 번쩍하고 사라지니 화려해도 된다.
우리 아우라는 **상시 켜져 있고 따라다닌다.** 같은 세기면 눈이 피곤하고,
무엇보다 돈 주고 꾸민 캐릭터가 안 보인다. 아우라가 주인공이 되면 실패다.
- v1 은 높이 200px 을 시켰다 → 캐릭터 셀이 224px 이니 사실상 전신 크기였다
- 색이 면을 꽉 채웠다 → 골드는 앱에서 3% 쓰는 색인데 한 덩어리가 통째로 금색이 됐다
- 프레임마다 크기가 두 배씩 널뛰었다 → APNG 로 묶으면 아우라가 커졌다 작아졌다 한다
v2 는 셋 다 못 박았다. **작고, 성기고, 안 흔들리게.**

■ 뽑는 방법
아래 블록을 통째로 복사해서 붙여넣는다. 한 번에 하나씩.

■ 뽑고 나서 (내가 함)
- 형광초록(#00FF00) 빼고 → 프레임 공통 bbox 로 잘라 정렬 → APNG 로 묶는다
- 캠프파이어·아기공룡과 같은 방식이다. 앱 코드는 한 줄도 안 바뀐다

공통 규칙 — 아래 세 블록 전부에 이미 들어가 있다 (참고용)
================================================================
· 캔버스 846 x 224 (141 x 224 짜리 6프레임 가로 한 줄)
· 이펙트는 **프레임 아래쪽 80px 안에만** 산다. 위쪽 144px 은 완전히 빈 초록이다
  → 캐릭터의 다리 언저리에만 걸리고 상반신·얼굴은 절대 안 가린다
· 꽉 찬 색면 금지. 가는 선 5~7 가닥 + 점 몇 개
· 6프레임의 실루엣 크기 차이는 **4픽셀 이내**
· 안티에일리어싱·블러·그라디언트 전부 금지

A. 발밑 열기 — 운동 후 몸에서 김이 오르는 정도  (헬스장 시즌 추천)
================================================================

Pixel art sprite animation strip, 6 frames in a single horizontal row.
Canvas exactly 846 x 224 pixels. Each frame exactly 141 x 224 pixels, evenly spaced, no borders or labels.
Background: solid pure green #00FF00 filling every frame completely. Never transparent, never black.

Subject: a SMALL, SUBTLE heat shimmer that rises only around a character's feet and shins. It will be drawn behind a character sprite. Do NOT draw any person, body, silhouette, or character — only the effect.

CRITICAL SIZE RULE: the effect must occupy ONLY the bottom 80 pixels of the 224-pixel-tall frame. The upper 144 pixels of every frame must be completely empty solid green. The effect is about 90 pixels wide, centered horizontally.

Style: 16-bit pixel art. Hard pixel edges only. NO anti-aliasing, NO blur, NO gradients, NO glow bloom. Every pixel is a solid color block. Diagonals must be visible stair-steps.

Design: sparse. Five to seven THIN wavy vertical lines, each only 1-2 pixels wide, rising from a faint flat ellipse on the ground. A few single-pixel embers float between them. Most of the area inside the effect stays green — this is a see-through shimmer, not a flame. Do not fill areas with solid color.
Colors: use only mid gold #F5C24B, pale gold #FFE9A8, and deep amber #8A4A12. Use them sparingly — the total colored pixels should look like thin strokes, not a mass.

Animation: the wavy lines drift upward and loop seamlessly (frame 6 flows into frame 1). The ground ellipse stays in the EXACT same place and size in all 6 frames. The overall silhouette height must not vary by more than 4 pixels between frames.


================================================================
B. 회전 링 — 발밑에서 조용히 도는 고리  (제일 절제된 안)
================================================================

Pixel art sprite animation strip, 6 frames in a single horizontal row.
Canvas exactly 846 x 224 pixels. Each frame exactly 141 x 224 pixels, evenly spaced, no borders or labels.
Background: solid pure green #00FF00 filling every frame completely. Never transparent, never black.

Subject: a thin rotating ring of light lying flat on the ground, seen in perspective, as if orbiting a character's feet. It will be drawn behind a character sprite. Do NOT draw any person, body, silhouette, or character — only the ring.

CRITICAL SIZE RULE: the ring must occupy ONLY the bottom 60 pixels of the 224-pixel-tall frame. The upper 164 pixels of every frame must be completely empty solid green. The ring is about 100 pixels wide and 30 pixels tall, centered horizontally.

Style: 16-bit pixel art. Hard pixel edges only. NO anti-aliasing, NO blur, NO gradients. Every pixel is a solid color block.

Design: a single flattened ellipse outline, 1-2 pixels thick — an outline only, NOT a filled shape. Four small spark pixels travel along the ellipse. Nothing else. The middle of the ellipse stays green.
Colors: use only action blue #3D7EFF, pale cyan #A8D4FF, and a few pure white pixels.

Animation: the sparks travel around the ellipse and loop seamlessly (frame 6 flows into frame 1). The ellipse itself is IDENTICAL in position, size, and shape in all 6 frames — only the spark positions change.


================================================================
C. 바닥 웅덩이 + 짧은 빛줄기  (1차 파워업 시안을 절반으로 줄인 것)
================================================================

Pixel art sprite animation strip, 6 frames in a single horizontal row.
Canvas exactly 846 x 224 pixels. Each frame exactly 141 x 224 pixels, evenly spaced, no borders or labels.
Background: solid pure green #00FF00 filling every frame completely. Never transparent, never black.

Subject: a small pooled glow on the ground with a few SHORT light beams rising from it. It will be drawn behind a character sprite. Do NOT draw any person, body, silhouette, or character — only the effect.

CRITICAL SIZE RULE: the effect must occupy ONLY the bottom 80 pixels of the 224-pixel-tall frame. The upper 144 pixels of every frame must be completely empty solid green. The ground pool is about 80 pixels wide; the beams reach at most 55 pixels above it.

Style: 16-bit pixel art. Hard pixel edges only. NO anti-aliasing, NO blur, NO gradients, NO glow bloom. Every pixel is a solid color block. Beam edges must be visible stair-steps.

Design: one flat ellipse pool on the ground, plus FIVE narrow beams, each 2-3 pixels wide, standing straight up from it. Leave clear green gaps between the beams — the beams must read as separate strokes, never merging into a solid mass. A few single-pixel bits sit beside the pool.
Colors: use only mid gold #F5C24B, pale gold #FFE9A8, and deep amber #8A4A12 for outlines. White only for two or three single pixels at the pool center.

Animation: the beams pulse gently and loop seamlessly (frame 6 flows into frame 1). The ground pool stays in the EXACT same place and size in all 6 frames. Beam height may vary by at most 4 pixels between frames — this is a gentle breathing motion, not a burst.

■ 안 되면 이 줄을 프롬프트 끝에 덧붙인다
================================================================

- 여전히 너무 크고 화려할 때:
  Make it much smaller and much sparser. The effect must look quiet and barely-there.
  It sits at a character's feet only. Reduce the number of colored pixels by half.

- 위쪽까지 이펙트가 올라올 때:
  The upper two thirds of every frame must be completely empty solid green #00FF00.
  Nothing may be drawn above the character's knee height.

- 색이 면으로 꽉 찰 때:
  This is a see-through effect made of thin strokes. Never fill an area with solid color.
  Green background must remain visible between every stroke.

- 흐릿하게(번짐) 나올 때:
  Every pixel must be a hard solid block. No smoothing, no blur, no soft edges, no glow bloom.
  Diagonal lines must be drawn as visible stair-steps.

- 프레임마다 크기가 널뛸 때:
  All 6 frames must share the same silhouette bounding box within 4 pixels.
  Only the internal animation phase may change. This is a subtle loop, not a growing burst.

- 캐릭터를 같이 그려버릴 때:
  Do not draw any person, body, silhouette, or character of any kind. Only the effect.

- 프레임 개수·간격이 안 맞을 때:
  Exactly 6 frames, evenly spaced, in one horizontal row. No frame borders, no labels, no numbers.
