# 히든 캐릭터 3종 + "비밀 관찰 파일" 등장 연출 — 설계

작성 2026-07-27. 상태: **설계 승인(대표), 구현 전.**
관련: [[project-murpy-character]], master-brief 2장(히든 3종), [[feedback-ai-dot-sheet-props]].

## 1. 목적 / 컨셉

머피월드 **히든 캐릭터 3종**(고정 캐릭터, 헬토리처럼 비커스터마이즈). 인테리어·머피소비 같은
**그라인딩이 아니라, 유저의 실제 운동 생활을 비추는 "정체성 미러"**로 준다.

- 톤 = **위트 + 미스터리**. 뻔한 영웅(챔피언) 금지, 킹받고 뜬금없는 페르소나.
- 해금 = **콕 찌르되 기전은 미스터리**(C안). 실제 데이터로 정확히 지목하되 "어떻게 아는지"는 안 밝힘.
- 목표 = "온 사람을 확 사로잡는 훅" + 공유 바이럴(AHA: *"이거 완전 나잖아? 앱이 날 어떻게 알았어?"*).

## 2. 캐릭터 3종 + 발동 조건(트리거)

전부 **checkins 컬렉션**만으로 계산(요일·서로다른센터·공백복귀). 숫자는 시작점(튜닝 예정).
데이터: `checkins/{uid}_{centerId}_{yyyymmdd}` = `{uid, centerId, centerName, day('YYYYMMDD'), at(ts), ...}`.
로드: 기존 `mwLoadCheckins()`.

| id | 이름 | 축 | 조건(시작점) | 콜드리드(예) |
|----|------|----|------|------|
| `cult` | 〈{요일}요일교 교주〉 (동적) | 특정 요일 몰림 | 최근 8주 체크인 ≥6회 **and** 최다 요일 비중 ≥58% | "너 지난 8주, {요일}요일에만 여섯 번 왔더라." |
| `somm` | 헬스장 소믈리에 | 장소 다양성 | 서로 다른 센터 ≥5곳 (도감 '원정' 카운트와 동일 데이터) | "헬스장 다섯 곳을 시음하셨네요. 정착은 언제…?" |
| `zombie` | 작심삼일 좀비 | 끊었다 복귀 | 이전 체크인 있음 → **14일+ 공백** → 다시 체크인(복귀 순간) | "죽었다 살아나셨군요. 또 돌아오셨네 ㅋㅋ." |

- **교주 요일은 동적**: 이름·콜드리드에 그 유저의 실제 최다 요일 삽입("화요일교"·"수요일교"…).
- **좀비는 윈백 보상**: 돌아온 걸 응원(리텐션 +). 공백 후 첫 복귀 체크인에서 1회 발동.

## 3. 등장 연출 — "비밀 관찰 파일 → 판정" (핵심)

축하 모달 금지. 앱이 **몰래 관찰해온 기밀 파일**을 들이밀며 정체를 지목하는 연출.
= 소름(미스터리) + 킹받음(로스팅) + AHA. 전 캐릭터 같은 틀, 증거만 다름.

**비트(교주 예시):**
0. 트리거 발동(체크인 저장 직후 등) → 화면 지직 글리치 → 어두워짐.
1. **기밀 파일 쿵 낙하** — `관찰기록 #머피-4721 [기밀]` (Galmuri 픽셀폰트, 검열 톤).
2. **증거 타자기 출력** — 포켓몬/쯔꾸르식 **한 글자씩 툭·툭·툭**(글자당 ~45ms, 줄마다 톡 소리+진동):
   - `대상: {닉네임}`
   - `관찰기간: 지난 8주`
   - `패턴 감지... ▓▓▓▓`  ← 검열블록(기전 은닉 = C)
   - `화요일 · 화요일 · 화요일 · 화요일 · 화요일`  ← 팩폭(소름 지점)
3. **판정 도장 쾅** — 기존 `.mw-inkstamp.slam`(붉은 인주) 재활용, 비스듬히 + `.mw-shake` 화면 흔들림
   → `판정: 〈화요일교 교주〉`.
4. 파일이 스르륵 벗겨지고 **그 뒤에서 캐릭터가 걸어나옴**(해당 스프라이트 걷기 프레임) — 한마디:
   *"찾았다. 화요일에만 오는 자여."*
5. **판정서 카드** 안착: 캐릭터 + 칭호 + 로스팅 한 줄 + `내 히든: 화요일교 교주` → **[자랑하기(공유)] [닫기]**.

증거만 교체:
- 소믈리에: `헬스장 5곳 시음 확인 ▓▓▓` → 판정 "헬스장 소믈리에" → "정착 못 하는 혀"
- 좀비: `사망 확인... 공백 14일... 부활 감지` → 판정 "작심삼일 좀비" → "또 돌아왔네 ㅋㅋ"

reduced-motion: 글리치·슬램·흔들림 생략, 텍스트는 즉시 표시(타자기 스킵).

## 4. 데이터 / 판정 로직

- **평가 시점**: 체크인 저장 성공 직후(`mwSealCheckin`) + 머피월드 진입 시 1회. 셋을 순서대로 검사, 새로 충족된 것 1개만 연출(큐).
- **판정 함수**(신규, 클라이언트): `mwEvalHidden(checkins)` →
  - `cult`: 최근 8주 필터 → 요일별 카운트(`at.toDate().getDay()`), total≥6 & max/total≥0.58 → {id:'cult', weekday}.
  - `somm`: `new Set(centerId).size ≥ 5`.
  - `zombie`: day 오름차순, 인접 간격 ≥14일이 있고 **가장 최근 체크인이 그 복귀분**이면 발동.
- **중복 방지 / 저장**: 해금분은 `users/{uid}.hiddenChars`(맵)에 저장 —
  `{ cult:{weekday:'화'}, somm:true, zombie:true }`. 해당 키가 이미 있으면 재판정·재연출 안 함.
  (교주는 요일을 값으로 들고 있어 칭호 렌더에 사용.)
- **소유·표시**: 헬토리와 동일하게 `_CHAR_BODIES`에 엔트리 추가 + 소유표시(로스터/도감). 커스터마이즈 불가(고정).

## 5. 공정성 하드룰 (master-brief 준수)

- **코스메틱 전용** — 매칭/피드 노출에 어떤 이점도 없음.
- **조건 비공개** — 체크리스트로 안 보여줌. `▓` 검열로 기전 은닉. 도감엔 미보유 시 실루엣만(힌트 없음).
- **시간대 강제 해금 아님** — 교주는 '요일' 인식(하루 중 시각 아님) + 강제가 아니라 기존 패턴을 알아보는 거울(대표 확인 완료 7-27).
- **베타 = 클라이언트 판정.** 서버 강제·어뷰징 방어(체크인 위조 등)는 공개 런칭 전 Cloud Functions 이관 과제(로드맵과 동일).

## 6. 구현 포인트 (단일 index.html)

- **재활용**: 판정도장 `.mw-inkstamp.slam`·`.mw-shake`, 오버레이 패턴(`_mwOverlay`/포털), 스프라이트 걷기
  (`_mwSpriteLayers`/시트 프레임), 도감 로스터(`QUEST_CHARS`/`_CHAR_BODIES`).
- **신규**: 타자기 유틸(글자 단위 setInterval, 검열블록 지원), `mwEvalHidden`, 판정서 카드 + 공유,
  `_CHAR_BODIES` 3종 엔트리 + 스프라이트 시트, `hiddenChars` 저장/로드.
- **공유**: 베타는 캡처 유도 카드 + 텍스트 네이티브 공유. 이미지 자동생성은 후순위.
- 캐시버스팅: 에셋·JS 변경분은 `sw.js` 버전 + `index.html` cache-bust 규칙 준수.
