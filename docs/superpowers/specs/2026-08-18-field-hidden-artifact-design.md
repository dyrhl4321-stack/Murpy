# 필드 히든 오브젝트 — 헬스장 바닥 합판 → 캐릭터 아우라

작성 2026-08-18 · 대표 승인 완료 · 구현 착수 전

## 무엇을 만드나

머피월드 **헬스장 필드** 바닥의 합판을 캐릭터가 **밟으면**, 쯔꾸르식 하단 대화창이 뜨고
그 자리에서 **발밑 아우라 고리**(캐릭터 이펙트)를 얻는다. 얻은 아우라는 꾸미기에서 켜고 끈다.

대표 원문(2026-08-18):
> 머피월드 내 방 말고 이동 눌러서 갈 수 있는 필드에 히든 오브젝트나 퀘스트 숨겨놓는 거 어때.
> 헬스장 필드 바닥에 쇠 같은 거 있잖아 합판 같은 거, 그거 열면 그 쯔꾸르 게임 하단부 대화창
> (우리 히든 캐릭터 획득 시 나오는 그런 대화창 무드)로 "헬스장 바닥 한쪽이 조금 이상하다..
> 한번 눌러볼까?" 같은 느낌으로. 스쿼드 + 헬스장 체크인 **필드 전용 아티팩트**,
> 캐릭터 주변에 헬스 관련 이펙트 주는 거지.

**대화창은 이미 다 있다 — 없는 건 '하단에 붙이는 자리' 하나뿐이다 (8-18 실측).**
대표가 말한 환세취호전·포켓몬식 하단 텍스트 박스는 `.mw-dossier` (index.html:922) 가 바로 그것이다:
검은 바탕 `#0e1015` + 3px 하드 테두리 `#05070c` + 파란 외곽선 `#2b3350`, `GalmuriMono11` 픽셀폰트,
`white-space:pre-wrap`. 지금은 히든 캐릭터 연출(`mwHiddenReveal`)이 이 상자를 **화면 한가운데**에
띄워 쓰고 있을 뿐이다. 한 글자씩 찍는 `mwTypewriter` 도 이미 있다(앱 통틀어 호출부가 그 한 곳뿐).

그래서 `#mw-fieldtalk` 는 **`.mw-dossier` 를 그대로 입힌 상자를 필드 하단에 붙이는 것**이다.
색·테두리·폰트를 새로 정하지 않는다. 새 시각 언어를 만들지 않는다.

## 획득 흐름

### 1. 트리거 — 밟고 나서, 두드려서 연다 (대표 확정 8-18)

**밟기 하나로 끝나지 않는다.** 밟으면 말이 걸리고, 실제로 여는 건 **두드리기**다.

```
window._FIELD_SPOTS = {
  gym: { plate: { tc:[11,12], tr:[7,7], x:727, y:494, w:103, h:73 } }   // 실측 확정 (8-18)
};
window._PLATE_TAPS_1 = 10;   // 조금 열림
window._PLATE_TAPS_2 = 30;   // 조금 열린 뒤 여기서 다 열림 (누적 40)
```

**밟기 판정** — `charMove()` 가 이동에 성공한 직후, 새 좌표가 핫스팟 칸인지 본다.
같은 칸에서 걸음마다 반복되지 않게, 칸을 벗어났다 다시 들어와야 재발동한다.

**두드리기 판정** — 합판 그림을 직접 탭한다.
★**조이스틱 예외 등록이 반드시 필요하다.** `#charworld-room` 은 방 전체가 드래그 조이스틱이고
`touchstart` 에서 `preventDefault` 를 부르기 때문에, 그냥 얹으면 **탭해도 아무 일이 없다**
(예전에 상자가 무반응이던 원인이 이것이고 코드에 주석으로 남아 있다). 두 곳을 손본다.
- `_initRoomJoy` 의 제외 선택자에 `.mw-plate` 를 추가 —
  `'.mw-fieldchip, .mw-sbox, #charworld-avatar, #mw-charmenu'` → 여기에 `, .mw-plate`
- 합판이 들어가는 `#mw-furn` 은 `pointer-events:none` 이므로 합판 `<img>` 에만 `pointer-events:auto`

**두드리는 맛은 소유 여부와 상관없이 준다** — 이미 가진 사람이 눌렀는데 아무 반응이 없으면
그냥 그림이 된다(공룡에서 얻은 규칙). 탭할 때마다 달그락 + 짧은 진동 + 찌부는 언제나 준다.

### 2. 연출 — 열렸다가 다시 닫힌다

**합판의 기본 상태는 언제나 닫힘이다.** 열린 모습은 지나가는 장면이고, 끝나면 닫힌 그림으로
돌아온다. '이미 열린 합판' 같은 영구 상태를 저장하지 않는다.

| # | 언제 | 그림 | 캐릭터 | 같이 일어나는 일 |
|---|---|---|---|---|
| 1 | 밟는 순간 | `closed` 덜컹 | 그대로 (tr 7) | 달그락 + 짧은 진동 |
| 2 | 이어서 | `closed` | 그대로 | 대화창: `헬스장 바닥 한쪽이 조금 이상하다..` / `한번 눌러볼까?` |
| 3 | 탭 **10번** | `ajar` | 그대로 | 대화창: `조금만 더 하면 열릴 거 같다..` |
| 4 | 탭 **30번 더** | `open` | **한 칸 뒤로 물러선다** (tr 7 → 8, 위를 본다) | 놀라 물러서는 찌부 |
| 5 | 이어서 | `open` | tr 8 에서 합판을 바라봄 | 대화창: 획득 문구 |
| 6 | 이어서 | 섬광 | 그대로 | 흰 섬광이 한 번 (CSS) |
| 7 | 끝 | `closed` | 조작권 돌려줌 | 획득 모달 |

**★캐릭터가 뒤로 물러선다 (대표 8-18).** 열린 구멍에 캐릭터가 빠진 것처럼 보이는 것도 막고,
세워진 뚜껑이 캐릭터에 가리는 문제도 같이 풀린다 — 이벤트(컷신)처럼 읽힌다.
z-index 로 합판을 캐릭터 위에 올리는 편법은 **쓰지 않는다.**

- 물러서는 칸은 `tr 8`. `_FIELDS.gym.map` 8행이 `###............#` 라 걸을 수 있다.
- **★물러서는 칸이 트리거 칸이면 안 된다.** 트리거를 `tr [7,7]` 하나로 잡은 이유가 이것이다 —
  `tr 8` 도 트리거였다면 물러서자마자 다시 발동해 무한루프가 된다.
- 점프가 아니라 **아래로 한 칸 걷기**다. `walk.png` 에 점프 프레임이 없으므로 걷기로만 만든다.
- 4~7 이 도는 동안은 조작을 막는다(`_mwPlateBusy`). 안 막으면 드래그로 구멍을 뚫고 지나간다.
- 대화창은 기존 `mwTypewriter` 를 쓰는 `#mw-fieldtalk` 하나다. 탭하면 다음 줄로 넘어간다.
- **탭 수는 상수 두 줄이다.** 40번이 많다 싶으면 `_PLATE_TAPS_1`·`_PLATE_TAPS_2` 만 고친다.
- **헬스장 필드를 떠나면 전부 초기화**된다(그림 `closed`, 탭 수 0). 전부 지나가는 상태다.
- **이미 그 시즌 걸 가진 사람**은 1~2 까지만 하고 `아까 열어본 그 합판이다.` 로 끝난다.
  두드리면 달그락 반응은 주되 열리지 않는다.
- 섬광은 그림이 아니라 CSS 다. 흰 판을 덮었다 지우는 것으로 충분하다.

### 3. 지급 — 그 자리에서 즉시

```
_seasonWrite(uid, { fieldAuras: arrayUnion(seasonKey), aura: seasonKey,
                    titles: arrayUnion(meta.title) })
```

**상자를 안 거친다.** 상자 규칙([[project_murpy_dino_egg]])을 어기는 게 아니라 **적용 대상이 다르다** —
상자 규칙은 **방에 배달되는 가구**용이고, 이건 캐릭터에 붙는 필드 이펙트라 방에 놓을 물건이 아니다.
공룡식 예외(`cond` 를 비워 자동 루프를 끊는 것)와도 다르다. 헷갈릴 자리라 `mwSeasonCheck` 와
합판 지급 함수 **양쪽에 주석으로 못 박는다.**

**얻으면 바로 켜준다.** 지급 시 `aura` 도 같은 키로 세팅한다 — 얻자마자 꺼져 있으면
획득 모달을 닫는 순간 아무 일도 안 일어난 것처럼 보인다. 끄는 건 꾸미기에서 한다.

**칭호를 같이 준다.** 획득 모달이 칭호 줄을 그리는데 안 주면 그 줄이 빈 채로 거짓말이 된다
(시즌 아이템들이 이미 그렇게 하고 있다).

쓰기가 성공한 뒤에만 로컬 상태에 반영한다 — 실패한 쓰기를 먼저 반영하면 새로고침에 사라지는
유령 지급이 된다(`mwSeasonCheck` 가 같은 이유로 그렇게 한다).

## 데이터 모델

| 자리 | 필드 | 뜻 |
|---|---|---|
| `users/{uid}` | `fieldAuras: string[]` | **가진** 아우라의 시즌 키 배열 (`['2026-08']`) |
| `users/{uid}` | `aura: string` | **켜둔** 시즌 키. `''` 이면 꺼짐 |
| RTDB `squadRooms/{sid}/players/{uid}` | `aura: string` | 남에게 보여줄 값. 켜둔 것만 실린다 |

소유와 장착을 나누는 이유는 대표 확정("꾸미기에서 골라 켜기") 때문이다. 시즌마다 아우라가 쌓여도
구조가 그대로 간다.

카탈로그는 상수 하나다:

```
window.FIELD_AURAS = {
  '2026-08': { color:'blue', name:'바닥의 불', title:'합판을 연 자',
               desc:'헬스장 바닥 아래에서 꺼내온 불꽃. 발밑에서 조용히 돈다.' }
};
```

이름·칭호·설명은 제안값이다. 대표가 바꾸면 이 상수 한 줄만 고친다.

`color` 는 파일명에 그대로 들어가므로 기존 화이트리스트 `_MW_AUR_COLORS` 를 반드시 통과시킨다
(프레즌스로 **남의 값**이 오는 자리라 그대로 쓰면 경로 주입이 된다 — 지금 코드가 이미 막고 있다).

## 소유·장착 판정

`_mwAurOf` 를 이렇게 바꾼다.

```
window._mwAurOf = function (uid, fromPresence) {
  if (window._AUR_TEST) return ...;                    // 시험 스위치는 그대로 남긴다
  const key = (uid === myUid) ? window._auraState.on : (fromPresence || '');
  const meta = window.FIELD_AURAS[key];
  return meta ? meta.color : '';
};
```

- **내 캐릭터** = 내 users 문서에서 읽은 `aura`
- **남** = 프레즌스에 실린 `aura`. `FIELD_AURAS` 카탈로그를 거치므로 카탈로그에 없는 값은 무시된다

붙이는 곳은 **두 군데뿐이다.**

1. **스쿼드 워킹룸** — `_sqCharEl(uid, nick, cfg, dir, title)` 에 `aura` 인자를 하나 더 받는다.
   호출부 4곳(`23238` 내 캐릭터 / `23341` / `23394` 정적 폴백 / `23473` 원격)에 값을 넘긴다.
   프레즌스 `send()` 페이로드에 `aura` 한 줄을 얹는다.
2. **머피월드 내 필드** — `_charApplyPos()` 끝에서 `#charworld-avatar` 에 `_mwAurApply` 를 부른다.
   **지금은 여기에 안 붙어 있어서 혼자 다닐 땐 아우라가 안 보인다.** 메모리에 "혼자 다닐 때
   항상 보이고"로 확정돼 있으므로 이번에 붙인다.

`.mw-aur` 는 부모 기준 백분율로 자리를 잡으므로 두 곳의 캐릭터 크기가 달라도 그대로 따라간다 —
착수 시 실제로 확인하고, 어긋나면 CSS를 고치지 말고 **덧붙여 보정**한다.

**안 붙이는 곳(대표 확정):** 톡 아바타 · 프로필 · 남의 방 구경. 캐릭터를 그리는 자리가 여러 곳인데
다 건드리면 조합 규칙이 갈라진다([[feedback_murpy_char_render_one_path]] 와 같은 이유).

## 꾸미기 — '이펙트' 칸

`mwRoomEdit()` 카탈로그 맨 아래, '한정 오브젝트' 줄과 같은 문법으로 칸을 하나 더 만든다.
**가진 게 하나도 없으면 이 칸은 아예 안 그린다**(한정 오브젝트가 그렇게 하고 있다).

- 머리글은 오늘 만든 `.mw-redit-cathead` 를 그대로 쓴다
- 카드를 누르면 켜기 ↔ 끄기. 켜진 카드는 스쿼드의 `입금 ✓` 토글과 같은 모양으로 표시한다
  (**틴트 칩 금지** — `background:none` + 테두리 + 글자색) [[feedback_murpy_no_tint_chips]]
- 한 번에 하나만 켠다(`aura` 가 단일 값이다)
- 켜자마자 내 필드 캐릭터에 즉시 반영하고, 스쿼드 필드에 있으면 프레즌스도 다시 보낸다

## 시즌 교체

- 합판은 **현재 시즌 키**(`_seasonEnsureMonth()`)의 아우라를 준다. 합판 자리는 그대로 두고
  안에 든 것만 시즌마다 바뀐다(대표 확정).
- 그 시즌 걸 이미 가졌으면 대화창은 뜨되 "아까 열어본 그 합판이다"로 끝난다.
- 다음 시즌이 되면 같은 합판이 다시 열린다. 지난 시즌에 얻은 아우라는 계속 소유·장착 가능하다.
- 새 시즌 아우라를 넣는 건 **뒷면 한 장 뽑아서** 아래를 돌리고 `FIELD_AURAS` 에 한 줄 넣는 일이다.
  `python char/make_aura_ring.py "<뒷면.png>" <색이름> 167 39`
- **`FIELD_AURAS` 에 이번 달 항목이 없으면 합판은 안 열린다.** 대화창은 뜨되
  "그냥 낡은 합판이다"로 끝난다. 그래서 첫 노출 시점은 코드가 아니라 **상수 한 줄로 정해진다** —
  `'2026-08'` 을 넣으면 지금 바로 열리고, `'2026-10'` 만 넣으면 10월에 열린다.
  월간 한정 오브젝트의 첫 시즌이 `2026-10` 이라([[project_murpy_season_limited]]) 둘을 맞출지는
  대표가 상수로 정한다. 이 문서는 `'2026-08'` 을 기본으로 적어둔다.

## 검증

배포 전:
1. `<script>` 6블록 전부 `node --check` 통과
2. `index.html` 의 `_SW_V` 와 `sw.js` 버전 숫자 일치

실앱(대표 확인):
1. 헬스장 필드에서 합판을 **밟으면** 달그락 + 대화창이 뜬다
2. 대화창을 끝까지 넘기면 획득 모달이 뜨고, 칭호도 같이 들어온다
3. 같은 칸을 다시 밟으면 "아까 열어본 그 합판이다"로 끝난다(중복 지급 없음)
4. 꾸미기에 '이펙트' 칸이 생기고, 켜면 내 필드 캐릭터 발밑에 고리가 돈다. 끄면 사라진다
5. 스쿼드 실시간 필드에서 **남에게도** 보인다
6. **안 가진 사람에게는 안 보인다** — `?aur=1` 없이 확인한다
