# 머피룸 — 초대해서 같이 놀기 설계

> 2026-08-20 · 대표 지시로 착수. 이 문서가 소스이고 CLAUDE.md 는 요약이다.

## 무엇을 만드나

내 머피룸에 **최대 4명(주인 포함)** 을 초대해서 같이 있고, 채팅하고, **같이 낙서를 그려
액자로 벽에 건다.** 초대 링크는 가입 안 한 사람도 열 수 있고, 그 안에서 뭔가를 하려고
누르는 순간 가입으로 유도한다.

세 가지 목적이 한 줄에 있다.
1. **유입** — 초대 링크 → 가입 없이 입장 → 게이트에 걸려 가입
2. **바이럴** — 방에서 만든 것(단체 스탬프·액자)이 카톡으로 나가고, 그게 다시 초대장이 된다
3. **리텐션** — 방에 남은 액자·흔적을 보러 주인이 다시 들어온다

## 왜 이 형태인가

**협동 낙서를 고른 이유.** 대표가 낸 안(같이 그림 → 액자)이 '같이 찍기'와 '흔적 남기기'를
하나로 합친다. 같이 그린 것이 곧 방에 남는 흔적이고, 그 액자가 곧 공유물이다.
덤으로 **AI 에셋이 한 장도 안 든다** — 32x32 도트를 정수배 NEAREST 로 그리면 우리 픽셀
규칙에 그대로 맞는다. 캐릭터를 직접 그리게 하는 건(메차 카멜레온식) 비용이 크지만
작은 낙서판 하나를 같이 칠하는 것은 싸다.

**범프는 넣지 않는다.** 폰을 부딪치는 동작이라 원격으로 모인 방에는 성립하지 않는다.
여기 넣으면 범프의 '대면 검증'이라는 의미가 희석된다 — 특허 축이라 더 조심해야 한다.

**같이 미니게임은 이번 범위 밖.** 실시간 게임 동기화는 비용 구조가 다르다.

## 이미 있는 것 (새로 만들지 않는다)

| 필요한 것 | 이미 있는 것 | 위치 |
|---|---|---|
| 초대장 화면 | `sqEnterChoice(sid, asGuest)` — 라벨·제목·부제 + 버튼 3개 | index.html:16692 |
| 가입 없이 입장 | `startGuestInvite` → `signInAnonymously` | index.html |
| 가입 유도 게이트 | `isTempAccount()` + `memberGate()` | index.html |
| 실시간 위치·presence | `squadRooms/{sid}/players` + `onDisconnect` | RTDB |
| 남의 방 보기 | `mwVisitRoom(uid)` · 방명록 `mwGbLoad/mwGbWrite` | index.html |
| 공유(카톡 썸네일) | `mwShareKakao` / `mwShareSheet` / `mwSaveStamp` + `_mwKakaoPrep` | index.html:20740~ |
| 카드 렌더 | `_dodgeCardImg` 와 같은 canvas → dataURL → `_mwStampData` 경로 | index.html |

**새 UI 문법을 만들지 않는다.** 초대장은 스쿼드 초대장의 문구만 바꾼 것이고, 공유 버튼은
`.mw-share`/`.mw-sbtn` 그대로다.

## 데이터

### RTDB — 실시간 (있다가 사라지는 것)

```
roomLive/{ownerUid}/
  players/{uid}          { nick, x, y, face, at, guest:bool }   // onDisconnect 로 지움
  chat/{pushId}          { uid, nick, text, at }                // 최근 것만 보관
  jam/                                                          // 협동 낙서
    open: bool                                                  // 주인이 열었나
    px/{r}_{c}: colorIdx                                        // 찍힌 칸만 존재(희소)
```

**낙서를 칸 단위 키로 두는 이유.** 줄 단위 문자열로 묶으면 같은 줄을 둘이 동시에 칠할 때
한 명이 진다. 칸 키는 충돌이 없고, 안 찍은 칸은 아예 없어서 데이터도 작다.

### Firestore — 영구 (남는 것)

```
users/{uid}
  roomArt: { png: <dataURL 또는 imgBB URL>, at, by: [uid...], nicks: [...] }   // 벽에 걸린 액자
  roomOpen: bool                                                              // 초대 받는 중
```

액자는 **한 장만** 둔다. 여러 장 걸기는 방 배치(`ROOM_ITEMS`)를 건드려야 해서 이번 범위 밖.
새로 그리면 이전 것을 덮는다 — 덮기 전에 확인을 받는다.

### 보안 규칙

RTDB `database.rules.json` 에 `roomLive` 추가.

```json
"roomLive": {
  "$owner": {
    ".read": "auth != null",
    "players":  { "$uid": { ".write": "auth != null && auth.uid == $uid" } },
    "chat":     { ".write": "auth != null" },
    "jam": {
      "open": { ".write": "auth != null && auth.uid == $owner" },
      "px":   { ".write": "auth != null" }
    }
  }
}
```

익명 계정도 `auth != null` 이라 그대로 통과한다. **Firestore 규칙은 손 안 대도 된다** —
`users` 읽기가 이미 열려 있고, 익명 계정은 로그인 상태이기 때문이다.
`roomArt` 쓰기는 본인 문서에만 되므로 기존 규칙 그대로다.

## 정한 것 (대표 8-20)

- **정원 4명** (주인 포함)
- **주인이 없어도 언제든 입장** — 실패하는 경우가 없어야 유입에 유리하다.
  대신 주인이 없으면 "주인이 자리를 비웠어요" 를 한 줄 띄운다.
- 초대 전용 UX = **협동 낙서 + 액자**, 그리고 **단체 스탬프**

## 단계

각 단계는 그것만으로 돌아가는 것을 낸다.

### 1단계 — 방에 모이기 (기반)

- `?room=<uid>` 딥링크 → 초대장 화면(스쿼드 초대장 문구만 교체)
- 가입 없이 입장(익명) / 이미 회원 / 둘러보기 — 스쿼드와 같은 세 갈래
- `roomLive/{owner}/players` presence + 이동 동기화 (스쿼드 워킹룸 구조 복제)
- 방 안 채팅 (말풍선)
- 정원 4명 초과 시 안내
- **비가입자 게이트** — 방명록·링 메뉴 4방향을 누르면 `memberGate()`
- RTDB 규칙 배포

여기까지가 유입 고리다. 이것만 나가도 초대는 돌아간다.

### 2단계 — 같이 찍기 (바이럴)

- 방에 있는 사람들을 한 프레임에 세운 단체 스탬프 카드
- 공유는 `_mwStampData` 에 넣고 기존 3버튼 그대로

### 3단계 — 협동 낙서 + 액자 (남는 것)

- 32x32 낙서판, 8~12색 팔레트, 칸 단위 RTDB 동기화
- 다 그리면 주인이 저장 → `users/{uid}.roomArt`
- 방 벽에 액자로 표시, 누르면 크게 + 공유
- 액자 카드에 "누구누구와 함께" 로 참여자 닉네임

## 안 하는 것

- 액자 여러 장 / 액자 위치 옮기기 (`ROOM_ITEMS` 를 건드려야 한다)
- 방에서 같이 미니게임
- 임시 계정에 아이템·머피 지급 (기존 규칙 그대로 — 계정을 버리면 같이 사라져 억울해진다)
- 방 안 음성·영상

## 위험

- **임시 계정이 늘어난다.** 스쿼드 초대와 같은 문제를 공유한다. 계정을 버리면 기록도
  사라지므로, 게이트 문구에서 "가입하면 남는다"를 분명히 한다.
- **낙서 욕설·음란물.** 32x32 도트라 표현력이 낮지만 완전히 못 막는 건 아니다.
  액자는 주인이 저장을 눌러야 남으므로 1차 필터는 주인이다. 신고 경로는 3단계에서 검토.
- **RTDB 비용.** 낙서는 칸마다 쓰기가 생긴다. 한 방 4명·32x32 라 상한이 낮지만
  드래그로 연속 칠할 때 쓰기가 몰린다 → 클라에서 같은 칸 중복 쓰기를 막고 쓰로틀한다.
