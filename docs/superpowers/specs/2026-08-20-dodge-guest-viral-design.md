# 덤벨 피하기 — 미가입자 바이럴 (링크로 바로 게임)

작성 2026-08-20 · 대표 승인 완료 · 구현 착수 전

## 무엇을 만드나

카톡·인스타로 퍼진 링크를 누르면 **가입도 로그인도 없이 3초 안에 덤벨 피하기가 시작**된다.
한 판 끝나면 그때 닉네임을 받고(임시계정), 랭킹에 올리려면 가입을 권한다.

대표 원문(2026-08-20):
> 카톡공유해서 바이럴 일으키려면 미가입자가 인스타링크던 카톡링크던 바로 그 게임화면으로
> 갈 수 있게 해야하잖아. (원래라면 머피월드 → 헬스장필드까지 가야하잖아 그 과정 생략)
> 인스타의 경우에는 사진만 스토리에 올라가고 링크는 따로 내가 첨부해야하잖아?
> 그래서 인스타 바이럴 전용으로도 바로가는 링크도 생성해줘야할듯.

## 지금 고리가 끊겨 있다 (착수 이유)

카톡 카드의 **「나도 해보기」를 누르면 머피 홈으로 간다.** 게임이 아니다.
`_dodgeShowShare` 가 `_mwShareMeta` 에 `link` 를 안 넣어서 `mwShareKakao` 가
`M.link || 'https://murpy.app/'` 의 기본값으로 떨어진다. 받은 사람은 로그인하고
머피월드 → 헬스장 필드까지 찾아가야 게임에 닿는다 — 사실상 아무도 안 간다.

## 대표 확정 (2026-08-20)

1. **비회원 기록은 랭킹에 안 올린다** — 가입 유도 지렛대로 쓴다.
   (`_hofRank` 가 이미 `!u.isAnonymous` 로 거른다. **규칙을 안 바꾼다.**)
2. **닉네임은 게임이 끝난 뒤에 받는다** (접근 B).
   근거는 앱에 이미 적혀 있는 원칙이다 — *"계정을 권하기 가장 좋은 순간 = 기록이 막 생긴
   직후. 그 전엔 지킬 게 없어서 '가입하세요'가 그냥 광고로 들린다."*
   스쿼드는 남이 내 이름을 보니 들어가기 전에 닉네임이 필요하지만, 혼자 하는 게임은
   **점수를 저장할 때** 처음 필요하다.
3. **링크에 도전장을 담는다** — `?game=dodge&n=<닉>&s=<점수>`.
4. **인스타 버튼이 링크도 같이 복사한다** — 버튼 3칸을 안 늘린다.
5. **카드 그림·카톡 문구는 손대지 않는다.**

## 이미 있는 것 (새로 만들지 않는다)

| 조각 | 위치 | 쓰임 |
|---|---|---|
| 게임 전체 | `dodgeOpen`/`dodgeGo`/`dodgeClose`, `#dodge-screen` | 그대로 |
| 공유 카드 그림 | `_dodgeCardImg` (캔버스 1080×1350) | **손 안 댐** |
| 공유 동작 | `mwShareKakao`/`mwShareSheet`/`mwSaveStamp` | 부르기만 |
| 공유 링크 자리 | `_mwShareMeta.link` (방 초대가 이미 씀) | **한 줄 채움** |
| 게스트 닉네임 시트 | `guestAskNick` / `guestSaveNick` | 그대로 재사용 |
| 익명 로그인 | `signInAnonymously` | 그대로 |
| 링크 복사 | `sqInviteCopy` 의 클립보드 문법 | 같은 방식 |
| 점수 저장 | `dodgeSave` (Firestore `users/{uid}.games.dodge`) | 비회원 경로만 추가 |
| 조작 방어 | `DODGE.MAX_SCORE = 9999` | 링크 파라미터에도 적용 |

## 1. 진입 — 링크를 누르면 바로 게임

```
https://murpy.app/?game=dodge&n=<닉네임>&s=<점수>
```

- `?game=` 을 읽어 게임을 여는 코드는 **덤벨 코드 블록 안 자체 IIFE** 로 둔다.
  푸시 알림 라우터(`?n=`)가 쓰는 것과 같은 방식이다.
- **인증을 기다리지 않는다.** 계정이 필요 없으므로 `onAuthStateChanged` 와 무관하게 즉시 연다.
- ★**비로그인 if/else 사슬(`_mwRoomInvite` → `_sqInviteSid` → 온보딩)을 건드리지 않는다.**
  그 사슬의 첫 가지가 방 초대인데, 다른 창이 지금 거기서 작업 중이다.
- 시작화면에 도전장 한 줄: `〈패수현님의 320점에 도전!〉`
- **점수·닉네임은 URL 에서 그대로 읽는다.** DB 조회가 없어서 빠르고,
  스토리에 올라간 사진의 숫자와 **항상 일치**한다(DB 를 읽으면 그 사이 기록이 바뀌어 어긋난다).
- 방어: 점수는 `0 ~ DODGE.MAX_SCORE` 로 자른다. 닉네임은 `textContent` 로만 넣고 12자로 자른다
  (URL 은 남이 고칠 수 있는 값이다 — `innerHTML` 로 넣으면 주입이 된다).
- 주소는 `history.replaceState` 로 즉시 지운다. 새로고침할 때마다 다시 튀면 안 된다.

## 2. 온보딩 충돌 — 사슬 대신 함수를 감싼다

★**온보딩(`#splash-ob`)은 z-index 30000, 게임은 2300 이다.** 링크로 들어오면
1.7초 뒤 온보딩이 게임을 통째로 덮는다. 반드시 막아야 한다.

막는 코드가 위 if/else 사슬 안에 있으므로, **사슬을 고치지 않고 `showSplashOnboarding` 을 감싼다.**

```
게임이 떠 있는 동안 호출되면 → 미뤄두고 표시하지 않는다
게임을 닫을 때 → 미뤄둔 게 있으면 그때 부른다
```

- 감싸는 시점은 **게임 링크를 처리하는 순간**이다(로드 완료 후). 정의 순서에 안 걸린다.
- 게임 링크로 들어온 경우에만 감싼다. 평소 흐름은 한 글자도 안 바뀐다.
- ★부수 효과가 오히려 낫다: **게임 → 나가기 → 그때 온보딩**. 재미를 먼저 보여주고 소개한다.

## 3. 점수 — 계정이 생길 때까지 폰에 들고 있는다

지금 `dodgeSave` 는 `if (!user) return;` 로 **조용히 버린다.** 비회원이 최고점을 내도 사라진다.

| 상태 | 저장 위치 |
|---|---|
| 계정 없음 | `localStorage` `murpy_dodge_guest` = `{best:<숫자>, recent:[{s,t,lv,at}, …]}` — Firestore 의 `games.dodge` 와 **같은 모양**. 옮길 때 변환이 필요 없다. `recent` 는 `DODGE_RECS_MAX`(20)로 자른다 |
| 임시계정 | Firestore `users/{uid}.games.dodge` (지금과 같음) |
| 정식 계정 | 같음. **uid 가 유지되므로 임시계정 때 점수가 그대로 따라온다** |

- 게임오버에 **「기록 남기기」** 버튼. 누르면 `signInAnonymously` → `guestAskNick` →
  닉네임 저장 후 **들고 있던 localStorage 점수를 그 계정으로 옮긴다.**
- 옮기고 나면 localStorage 를 비운다. 두 벌로 남으면 어느 게 진짜인지 알 수 없어진다.
- `guestSaveNick` 은 끝에서 `_guestGoSquad()` 를 부른다. 게임에서 왔으면 스쿼드로 가면 안 되므로
  **일회용 콜백 `window._guestAfter` 를 둔다** — 설정돼 있으면 그걸 부르고 비운다.
  안 설정돼 있으면 지금 동작 그대로다(스쿼드 흐름 무영향). ★이것이 유일하게 공용 코드를
  건드리는 자리다(`_guestGoSquad`, 2줄). 다른 창이 만지는 방 초대와는 다른 함수다.

## 4. 공유 — 두 줄

1. `_dodgeShowShare` 의 `_mwShareMeta` 에 `link` 추가:
   `https://murpy.app/?game=dodge&n=<닉>&s=<점수>` (닉네임은 `encodeURIComponent`)
2. 인스타 버튼: `mwShareSheet()` 를 부르기 **전에** 같은 링크를 클립보드에 넣고
   토스트 `링크도 복사했어요 · 스토리에 붙여넣으세요`.
   복사는 `sqInviteCopy` 와 같은 문법(`navigator.clipboard` → 실패 시 textarea 폴백).
   ★복사는 **탭 제스처 안에서** 해야 브라우저가 허용한다. 공유시트를 연 뒤에 하면 막힌다.

**카드 그림(`_dodgeCardImg`)·카톡 문구(`title`/`desc`/`btn`)·버튼 3칸은 그대로 둔다.**
문구는 이미 `나도 해보기` 라 도전장에 그대로 맞는다.

### 인스타 링크 자동첨부는 지금도, 네이티브에서도 장담 못 한다
- 웹앱에서는 **불가능**하다. `instagram-stories://` 스킴은 네이티브 앱만 쓸 수 있다
  (클립보드에 이미지를 넣고 스킴을 여는 방식이라 브라우저에 권한이 없다).
- 네이티브로 가면 **공유시트를 건너뛰고 스토리를 바로 여는 것**은 된다. 그러나
  **링크(`contentURL`) 자동 첨부는 메타 승인 파트너만**으로 알려져 있다(2026-08-20 기준 미확정).
- → **링크 복사 버튼은 웹앱 임시방편이 아니다.** 네이티브에 가도 계속 필요하다.

## 5. 전환 — 랭킹을 지렛대로

★**권유 팝업은 이미 있다: `window.guestNudge()`.** 새로 만들지 않는다.
임시계정에게만 뜨고, `murpy_guest_nudge_<날짜>` 로 **하루 한 번** 제한이 이미 걸려 있으며,
문구도 이미 맞다 — *"지금은 임시 계정이라 이 폰에서 앱을 지우면 같이 사라져요.
계정을 만들면 기록은 그대로 옮겨가요."*

- 임시계정이 게임을 끝냈을 때 `guestNudge()` 를 부른다(하루 한 번은 그 함수가 알아서 지킨다).
- 게임오버 화면에는 한 줄만 덧붙인다: **「랭킹에 올리려면 가입」**.
  임시계정이 랭킹에서 빠지는 건 사실이므로 광고가 아니라 안내다.
- ★**계정이 아예 없는 사람에게는 `guestNudge` 를 부르지 않는다** — 그 함수는
  `!user.isAnonymous` 면 그냥 돌아간다. 그 사람에게 필요한 건 가입이 아니라
  **먼저 「기록 남기기」**(3장)다. 순서를 지킨다.

## 6. 안 하는 것

- 머피월드·헬스장 필드 진입 경로 변경 (회원용 그대로)
- 임시계정에게 게임 외 기능 열어주기
- `_notMember` / `memberGate` / `requireRealAccount` 수정 — **한 글자도 안 건드린다**
- 랭킹 노출 규칙 변경
- 카드 그림·카톡 문구·공유 버튼 3칸 변경
- 테니스·골프 미니게임 (별도)

## 다른 창과 겹치지 않게 (동시 작업 규칙)

다른 창이 같은 `index.html` 에서 **머피월드 방 초대**를 만든다.

| 자리 | 누가 |
|---|---|
| 비로그인 if/else 사슬 (`_mwRoomInvite` 가지) | **다른 창** — 나는 안 건드림 |
| `?room=` / `_mwRoomInvite` / `mwVisitRoom` | **다른 창** |
| `?game=` / `dodge*` / `#dodge-*` / `DODGE` | **나** |
| `_notMember`/`memberGate`/`requireRealAccount` | **아무도 안 건드림** |
| `mwShareKakao`/`mwShareSheet`/`mwSaveStamp` | 양쪽 다 **부르기만** |
| `_guestGoSquad` | **나** (콜백 훅 2줄) |
| `sw.js` + `_SW_V` | **새 에셋 파일을 추가할 때만** 올린다 |

★`index.html` 은 sw 가 `cache:'no-store'` 로 매번 새로 받으므로 **HTML 변경은 sw 버전을
안 올려도 폰에 간다.** 그래서 sw 충돌을 대부분 피할 수 있다.

## 검증

배포 전:
1. `<script>` 블록 전부 `node --check` (`tools/dogam-syntax-check.mjs`)
2. 순수함수 테스트 (`tools/tests/dodge-guest.test.mjs` 신규)
   - 링크 파싱: 정상값 / `s=999999`(잘림) / `s=abc`(0) / 12자 넘는 닉 / 빈 값 / `n=<script>`
   - 링크 만들기: 닉네임이 `encodeURIComponent` 되는가(공백·`&`·한글)
   - localStorage 승격: 게스트 기록이 Firestore 모양 그대로 옮겨지고 원본이 비워지는가

실앱(대표 확인):
1. 로그아웃 상태에서 `murpy.app/?game=dodge&n=패수현&s=320` → **로그인 없이 바로 게임**,
   시작화면에 도전장 한 줄
2. 그 상태로 1.7초 넘게 둬도 **온보딩이 안 덮는다**. 게임을 나가면 그때 온보딩이 뜬다
3. 한 판 하고 게임오버 → 「기록 남기기」 → 닉네임 → 점수가 남는다
4. 그 뒤 정식 가입 → **점수가 따라온다**
5. 카톡 공유 → 받은 사람이 「나도 해보기」 → **게임으로 간다**(지금은 홈으로 간다)
6. 인스타 버튼 → 공유시트가 뜨고 **링크가 이미 복사돼 있다**
7. 임시계정은 명예의 전당 게임 탭에 **안 뜬다**
8. 링크를 손으로 고쳐도(`s=999999`, `n=<script>`) 안 깨진다
