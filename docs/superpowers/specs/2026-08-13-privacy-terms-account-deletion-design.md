**머피 조항이 특히 필요하다.** 현재 `CREDITS_MODE='beta'`(적립만, 차감 없음)이지만

**만남 서비스라 반드시 넣을 것**: 오프라인 만남·운동 중 발생한 사고에 대한 책임 범위,
이용자 간 분쟁에 회사가 개입하지 않는다는 조항.

## 산출물 ③ 앱 내 계정 삭제

### 위치와 흐름

마이페이지(`mypage-panel`) `panel-body` **맨 아래**, 로그아웃과 분리된 작은 회색 텍스트 버튼.
누르면 → 경고 모달(무엇이 지워지고 무엇이 남는지 명시) → 한 번 더 확인 → 실행(진행 표시).

**새 UI를 만들지 않는다.** 기존 모달·토스트 문법을 그대로 쓴다.
(8-12 교훈 [[feedback_murpy_reuse_existing_ui]])

### 처리 원칙 — 내 것은 지우고, 남과 얽힌 것은 익명화

전부 하드 삭제하면 **벙주 정산이 깨지고**(스쿼드 출석·입금) **상대 화면의 대화가 반쪽만 남는다.**
개인정보보호법상 식별정보를 제거하면 파기로 인정되므로, 식별정보만 확실히 없앤다.

| 즉시 삭제 | 익명화해서 남김 |
|---|---|
| `users/{uid}`의 닉네임·사진(photos·workoutPhotos)·생년월일·나이·성별·지역·소개·`fcmTokens`·`faceVerified` | 스쿼드 멤버 문서 — 출석·입금 기록 보존, 표시명만 `탈퇴한 사용자` |
| 내가 쓴 `feed` · `bamboo` 글 | 채팅 메시지 — 상대 대화 이력 보존 |
| 내 `checkins` · `likes` · `matches` · `notifications` | 남의 글에 단 댓글(하위 컬렉션이라 일괄 조회가 어렵다) |
| Firebase Auth 계정 | |

`users/{uid}` 문서 자체는 **지우지 않고** 껍데기로 남긴다 —
`{ deleted: true, deletedAt, nickname: '탈퇴한 사용자', photoURL: '', photos: [], ... }`.
통째로 지우면 남의 화면 곳곳(스쿼드 멤버 목록·채팅 상대·방명록)이 "알 수 없음"으로 깨진다.

### 실행 순서 — ★개인정보 제거를 가장 먼저

중간에 끊겼을 때 최악은 **개인정보가 남는 것**이다. 그래서 순서를 뒤집는다.

1. `users/{uid}` 익명화 — 닉네임·사진·생년월일·성별·지역·소개·FCM 토큰 제거, `deleted:true`
2. 내 콘텐츠 삭제 — `feed` → `bamboo` → `checkins` → `likes` → `matches` → `notifications`
   (각 단계 실패해도 다음으로 진행. 한 건도 못 지워도 1번이 끝났으면 개인정보는 이미 없다)
3. Firebase Auth 계정 삭제(`deleteUser`)
   - `auth/requires-recent-login` → "보안을 위해 다시 로그인한 뒤 삭제해 주세요" 안내 후
     재로그인 유도. **이때 1·2번은 이미 끝나 있으므로 개인정보는 남지 않는다**
4. 로그아웃 → 홈

같은 구글/카카오 계정으로 다시 로그인하면 **새 uid**가 발급되어 완전 신규 가입이 된다.

### 앱 쪽 후속 처리 (안 하면 탈퇴자가 화면에 남는다)

- **매칭 후보에서 제외** — `renderMatch`가 `deleted === true`인 유저를 건너뛴다
- **프로필 열기 차단** — `openUserProfile`이 `deleted`면 "탈퇴한 사용자예요" 토스트 후 닫는다

### 웹에서도 삭제 요청 가능해야 한다

플레이 정책은 앱을 지운 사용자를 위해 **앱 밖 경로**도 요구한다.
`privacy.html` 안에 "계정 삭제 요청" 절을 두고 절차(앱 내 경로 + 메일 요청)를 적는다.
별도 페이지는 만들지 않는다.

## 검증

1. 로그아웃 상태(시크릿 창)에서 `murpy.app/privacy`, `murpy.app/terms`가 열린다
2. 모바일 폭에서 표가 가로로 안 넘친다
3. 테스트 계정으로 실제 탈퇴 → Firestore 콘솔에서 `users/{uid}`에 식별정보가 없고 `deleted:true`인 것,
   `feed`·`checkins`에 내 문서가 없는 것을 **눈으로 확인**한다
4. 탈퇴한 계정이 다른 계정의 매칭 카드에 뜨지 않는다
5. 같은 구글 계정으로 재로그인 → 온보딩부터 새로 시작된다
