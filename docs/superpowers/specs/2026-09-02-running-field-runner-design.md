## 1. 러닝존 필드 (걸어다니는 다섯 번째 필드)

- `_FIELDS.running` 추가: `{ name:'러닝존', src:'char/fields/field_running.png?v=1', grid:16, start, map }`
  - 기존 home/gym/tennis/golf 와 같은 규격: 1024×1024, 16×16 칸 충돌맵.
  - 걷기 가능 = 트랙 밴드 + 아래 잔디밭. 강·스카이라인(위쪽 약 5칸)은 벽.
- 배경 그림: `tools/gen_asset.py` 로 시안 참고 재생성.
  - 시안에서 유지: 도시 스카이라인·한강·주황 트랙·잔디·벤치·정수기·가로등·나무.
  - 시안에서 제거: 초록 격자선(기존 필드에 격자선 없음)·우하단 워터마크.
  - 스타일 레퍼런스로 기존 필드(field_tennis.png)를 같이 넣어 화풍·소품 크기를 맞춘다.
- 필드 바에 '러닝존' 버튼 추가. "한강 러닝존 … 곧 열려요" 문구 2곳에서 러닝존 제외.

## 2. 머피런 — 원버튼 러너 (러닝존 전용 미니게임)

- 구조 = 머피 테니스 패턴 그대로 복사(id만 run 으로): 전용 풀스크린 `#run-screen`,
  타이틀(눌러서 시작/내 기록 보기) → 난이도 3단계 → 시작 → 결과·공유·다시 하기.
  - 입장 버튼: `runFieldBtn(key)` — 러닝존 필드에서만 (charSetField 훅 줄에 추가).
  - 게스트 링크 `?game=run` (dodge/golf 와 같은 흐름).
- 조작: 자동으로 오른쪽으로 달린다. 탭 = 점프, 길게 = 더 높이·멀리. 조작은 이 하나뿐.
- 장애물(왼쪽으로 흘러온다):
  - 허들(낮음, 짧은 점프) · 물웅덩이(넓음, 긴 점프) · 비둘기(무릎 높이로 날아옴 — 타이밍 다름)
  - 자전거(난이도 중부터, 빠르게 접근 — 멀리서 벨 소리 예고)
- 규칙: 거리 = 점수(m). 시간이 갈수록 속도 증가. 충돌 = 꽈당 종료.
  난이도 하만 1회 일어나서 계속(부활 1). 난이도별 시작 속도·가속·장애물 밀도 차등.
- 시점·배경: 옆에서 본 횡스크롤 2겹 패럴랙스 —
  - 먼 겹(하늘·스카이라인·강): 느리게. `run_bg.jpg` 한 장을 가로 반복.
  - 트랙 겹: 빠르게. `run_track.png` 타일 반복(골프 golf_grass 방식).
- 캐릭터: `_charRenderTo` 결과의 **옆모습(right) 걸음 프레임**을 빠르게 돌려 달리기.
  점프는 그림자를 트랙에 두고 몸만 뜨는 방식(홀인 머피 공과 같은 규칙).
- 명예의 전당: HOF 게임 종목에 `run: { label:'러닝', unit:'m', game:'머피런' }` 추가.
- 보상: 테니스와 같은 구조를 그대로 따른다(따로 새 경제를 만들지 않는다).
- 효과음: 기존 sfx 채널 재사용 — 발소리(주기)·점프·착지·꽈당·신기록. 새 채널 안 만든다.
- 타이틀 그림: 글자 없는 그림 생성 + PIL 도트 글씨(제미나이 한글 "며피" 사고 방지).
